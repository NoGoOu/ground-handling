# Ground Handling App

Nyílt forráskódú webalkalmazás repülőtéri földi kiszolgálás (ground handling) szervezésére. A projekt részletes leírása: [CLAUDE.md](CLAUDE.md).

## Fejlesztés

Követelmény: Node.js 24.

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # unit tesztek
npm run lint
npm run build
```

A Docker Compose-os indítás leírása a későbbi lépésekben kerül ide.
